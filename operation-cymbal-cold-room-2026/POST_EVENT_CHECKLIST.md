# Post-event publication checklist

- [ ] Competition ended and organiser rules explicitly permit publishing writeups.
- [ ] Each incident summary is based on my firsthand observations.
- [ ] Challenge titles, findings, tools, results and rank are verified.
- [ ] Timestamp conversions and evidence references are internally consistent.
- [ ] Alternative hypotheses and investigation limitations are documented.
- [ ] Secrets, flags, identifiable information and restricted materials are removed.
- [ ] Screenshots and logs are shared only with permission and necessary redaction.
- [ ] Third-party assistance is credited accurately and within competition rules.
- [ ] Git history and old commits are checked for accidentally committed secrets.
- [ ] Links in README resolve and no placeholder language is presented as final results.
